Welcome to TinyMatrix's documentation!
======================================

TinyMatrix is a minimal, dependency-free Python library that provides a clean
Matrix type with linear algebra operations: construction, arithmetic, matrix
multiplication, decompositions (LU, QR, Cholesky, SVD, Eigenvalues), solvers,
sparse formats, and optimizations.
